### ⚠️ Багфиксы (31.08) ✅
- [x] **БАГ «ответ от Hermes не отображается» — ИСПРАВЛЕН, корень тройной:**
  1. **tool_calls**: при числовых запросах модель вызывает калькулятор → при `stream:false` первый шаг ответа пустой → плагин показывал пустоту. **Фикс: `stream:true` + `noctalia.httpStream`** — tool-цикл выполняет сам Hermes, финальный текст приходит в `delta.content`.
  2. **ui.scroll не рендерил контент** в DONE/WORKING (ответ и стриминг были невидимы). **Фикс: заменили на `ui.label`**; кнопки прижаты вниз через `ui.spacer({flexGrow=1})`. `ui.scroll` остался только в списке команд (там работает).
  3. **string.gsub ломал подстановку `{input}`**: внутренний `gsub(source,"%%","%%%%")` возвращает (строку, count) — count попадал в параметр `n` внешнего gsub → 0 замен. **Фикс: скобки `(...)` отбрасывают count.**
- [x] **Локализация настроек**: настройки в GUI Noctalia локализуются системным языком Noctalia (не настройкой `language`) — задокументировано в README (раздел «Локализация»), поведение Noctalia, не баг плагина.
- [x] **Ревью-фиксы**: env_file не читается → ранний выход в DONE (без бесполезного запроса); `t()` с fallback на en; `handle.stop()` в onClose (отмена стрима при закрытии); trim ведущих переносов ответа.
